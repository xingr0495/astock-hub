# 数据接入说明

`astock-hub` 是数据聚合与研究工具，**不随仓库销售或分发第三方数据**。可用功能取决于你本机的数据文件、公开接口可用性，以及你自行取得的服务授权。

## 数据分层

| 类型 | 接入方式 | 主要用途 |
|------|----------|----------|
| 公开行情接口 | 无需 Key，默认可用 | 个股快照、指数、K 线、分时等 |
| 公开产业资讯 | 内置 RSS 源清单 | 产业新闻聚合与检索 |
| 本地历史数据 | 自行初始化或放入 Parquet 文件 | 全市场看板、情绪、主线、策略扫描 |
| hithink-finance | 自行安装并授权 CLI | 历史数据维护及补充行情 |
| Tushare | 在「数据源」页填写自己的 token | 对应适配接口的数据补充 |
| TickFlow 在线行情 | 在「数据源」页填写自己的 Key | 已接入的在线行情与全球个股接口 |
| TdxQuant | 在「数据源」页填写自己的 Key | 当前提供凭证管理与连接探测，实际路由以版本说明为准 |
| 大模型 | 在「大模型」页自行配置 | AI 问答、摘要、复盘和研究辅助 |
| 自有纪要报告 | 配置自己已授权的本地目录 | 信息面检索；仓库不附带纪要内容 |

> “已保存凭证”不等于该数据源的所有接口都已接入。每个数据源只覆盖当前代码已实现的适配范围，免费服务也可能有限流、延迟或临时不可用。

## 推荐配置方式

优先使用面板：

1. 打开「数据源」保存行情服务配置，并使用可用的「测试连接」。
2. 打开「大模型」添加自己的 OpenAI 兼容接口或其他受支持通道。
3. 如需通知，在「推送设置」中配置自己的 Webhook，并保持推送开关默认关闭，确认无误后再启用。

密钥和运行数据均不应提交到 Git。`config.toml`、`.env`、`data/`、`frontend/node_modules/` 已在 `.gitignore` 中排除。

## 本地目录约定

- `data/hithink_cache/`：名称、日历、概念映射与历史面板缓存
- `data/market/`：全市场日线 Parquet 数据
- `data/zsxq_output/`：可选的用户自有纪要报告（需自行提供）
- `data/investment_news/`：资讯运行产物

这些目录可能因版本和配置不同而变化。迁移前请先备份，且不要把自用数据误当成公开示例数据分发。

## 数据合规边界

- **代码许可 ≠ 数据授权**。MIT 许可证只覆盖本仓库代码。
- 免费接口并不自动意味着允许商用、批量抓取或二次分发。
- 付费账号通常只允许授权本人使用，不要把凭证或付费内容打包分享给他人。
- 行情、研报和纪要可能有延迟、缺漏或错误，重要信息应独立核实。
- 本软件不构成投资建议，不提供荐股或代客理财服务。
